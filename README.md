## 🛠️ Tech Stack & Architecture

| Category | Technologies & Standards |
| :--- | :--- |
| **Core Markup** | Semantic HTML5 (`form`, accessible inputs, structured containers) |
| **Styling & Layout** | CSS3 (Flexbox, Responsive Media Queries, custom styling) |
| **UI / UX Focus** | Mobile-First approach, cross-screen adaptability, clear visual feedback |
| **Hosting & CI/CD** | Static deployment via GitHub Pages |
| **Version Control** | Git & GitHub |

---

## 🚀 Key Implementation Highlights

- **Cross-Device Responsiveness:** Adaptive layout engineered to render cleanly across desktop monitors, tablets, and mobile screens.
- **Clean Code Structure:** Separation of concerns between markup (`index.html`), stylesheet (`public/css/styles.css`), and design guidelines (`style-guide.md`).
- **Lightweight Performance:** Zero external framework dependencies, ensuring fast page load times and minimal asset overhead.
